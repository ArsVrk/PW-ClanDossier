Чорна Рада — локальний переглядач бази персонажів Perfect World

Зміни v0.9:
- Фізичне зменшення розміщене одразу під точністю, магічне — під ухиленням.
- Додані необов’язковий Basic Auth і сценарії для захищеного пробного доступу через Cloudflare Quick Tunnel.

Зміни v0.7:
- Фізичне та магічне зменшення показуються над фізичною атакою/захистом.
- Сортування загального списку — натисканням на заголовки таблиці, як в Excel.
- Історія сканів інтерактивна: натисни рядок, щоб відкрити саме цей знімок характеристик та екіпіровки.
- Зірочка наприкінці рядка історії задає скан за замовчуванням. Вибір зберігається у scan_defaults.json, SQLite не змінюється.
- Якщо зірочку ще не встановлено, стандартно обирається найновіший скан «Без бафів». Якщо такого немає — найновіший скан без повного бафу, потім найновіший доступний.
- Повний NPC-баф визначається наявністю всіх статусів ID 28, 31, 64, 65, 66, 68. Додаткові статуси дозволені. Такий скан позначається «Повний баф» і доступний в історії як окремий знімок.
- У деталях повернуті фізичне та магічне зменшення (%).
- Прибрано нативну підказку з ID каменю: тултіп показує лише назву.
- Обробка від'єднання браузера не засмічує консоль помилками WinError 10053.

Встановлення:
1. Розпакуй архів у нову папку.
2. Скопіюй свою PW_ClanDossier.sqlite3 у цю папку.
3. Запусти START_SITE.bat.
4. Відкрий http://127.0.0.1:8787

Сайт читає SQLite без змін. Обраний за замовчуванням скан зберігається окремо у scan_defaults.json. Для підвантаження відсутніх назв та іконок потрібен доступ до Інтернету.


Пробний віддалений доступ без оплати через Cloudflare Quick Tunnel:
1. На цьому ПК встанови Python, як для звичайного запуску сайту.
2. Завантаж cloudflared для Windows з офіційної сторінки Cloudflare та поклади cloudflared.exe у папку сайту.
3. Запусти START_SITE_TUNNEL.bat і задай спільний пароль для офіцерів. У вікні залишиться працювати сервер, прив’язаний лише до 127.0.0.1. Логін для браузерного запиту: officer.
4. В іншому вікні запусти START_CLOUDFLARE_TUNNEL.bat. Скопіюй HTTPS-адресу trycloudflare.com, яку покаже консоль, і передай її офіцерам окремо від пароля.
5. Для доступу комп’ютер, серверне вікно і тунельне вікно мають бути увімкнені. Після перезапуску Quick Tunnel адреса зазвичай змінюється.

Важливо: це пробний варіант, не постійний хостинг із гарантією доступності. Не запускай звичайний START_SITE.bat одночасно з тунельним режимом, якщо не хочеш також відкривати сайт у локальну мережу. Не передавай URL і пароль стороннім: сайт показує внутрішні дані персонажів.

Хмарні безкоштовні платформи зручніші лише на перший погляд: наприклад, Render Free засинає після 15 хвилин без трафіку, а зміни локальних файлів, зокрема SQLite і файлу зірочок, губляться після засинання/перезапуску. Для цієї програми це означає, що вибір скану за замовчуванням може скидатися.


Batch-file compatibility note: the .bat launchers use ASCII-only command text to avoid Windows CMD encoding/parsing errors. In START_SITE_TUNNEL.bat use a shared password containing only English letters and digits.
